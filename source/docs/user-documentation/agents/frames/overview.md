# Overview

> Turn agent outputs into living, interactive content.

<Note>
  Frames replace the previous Data Visualization feature with more powerful interactive capabilities.
</Note>

## What are Frames?

Instead of static text responses, your agents can create interactive components such as reports with live data, dashboards, calculators, data visualizations, and other interactive elements.

Frames are interactive by design. You can hover over charts to see details, click legends to filter data, and use buttons to switch perspectives.

Frames can also evolve after they are created. Ask your agent to add a regional breakdown, change the time period, or try a different visualization. Your Frame updates while preserving the existing work.

Frames are files that you can share through links. Recipients can view the same live data and interact with the available controls. You can share them internally or externally with clients and partners using secure, token-gated links.

## Add Frames to an agent

When creating or editing an agent:

1. Open **Add capabilities** in the Agent Builder.
2. Select the **Create Frames** skill.
3. Save the agent.

You can then ask the agent to create a report, dashboard, visualization, or another interactive output.

<Note>
  All Frames created in a conversation are accessible from the folder icon. You can download or share them from there.
</Note>

## Revert changes to a Frame

If an agent's latest edit is not what you wanted, you can undo it.

When an agent has edited a Frame and a previous version exists, a **Revert the last change** button appears in the Frame panel. Reverts happen one step at a time. Click the button again to move further back through the Frame's history.

You can also ask the agent to restore an earlier version, for example: **Restore the Frame as it was yesterday.**

## Manage Frame sharing

Workspace admins can control how members share Frames. These settings determine which sharing options are available to users.

To configure the Frame sharing policy:

1. Open the **Admin** tab.
2. Go to **Workspace settings**.
3. Select the preferred **Frame sharing policy**.

Public sharing is enabled by default, allowing members to share Frames externally with clients and partners.
