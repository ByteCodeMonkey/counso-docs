# Raycast Extension

Run any Dust agent on text you've selected anywhere on your Mac. The agent's response replaces your selection in place, so you do not need to switch apps or copy and paste.

## Installation

Visit the [Raycast Store extension page](https://www.raycast.com/albandum/dust-tt) and click **Install Extension**.

## Setup

### Login to Dust

Authenticate with your Dust workspace credentials.

**Note:** If your workspace is in our EU region ([https://eu.dust.tt](https://eu.dust.tt)), update the Dust URL in the Raycast extension settings.

### Pick a workspace

Select the Dust workspace you want to use if you belong to several workspaces.

### Start talking to your agents

Open Raycast with `⌘ Space`, search for an agent, and start chatting.

## Bind an agent to a shortcut

The fastest way to use Dust is to assign a keyboard shortcut to an agent, then trigger it on selected text in any app. This works for grammar fixes, translations, rewrites, and other tasks where you want the agent's response to replace the selected text.

1. Open **Raycast Settings → Extensions → Dust**.
2. Click **Set up Replace Selection**.
3. Pick the agent you want to bind, such as a Grammar, Translate, Tone of Voice, Rewriter, or Support agent, then click **Create Quicklink**.
4. In the Quicklinks list, find the new entry and click **Record Hotkey**. Press the key combination you want, such as `⌘G`.
5. Repeat these steps for as many agents as you like. You can use a different shortcut for each agent, such as `⌘G` for Grammar and `⌘T` for Translate.

To use a shortcut, select text anywhere on your Mac and press the assigned key combination. The selected text is sent to the bound agent, and the agent's response replaces it in place. Raycast runs the command in the background and displays notifications for progress or errors instead of opening a window.

<Info>
  This works system-wide, not only inside Raycast or Dust. You can select text in Apple Notes, a Slack message, a browser, an email draft, or any other app where text can be selected.
</Info>

## General shortcuts

For quick access to a chat without replacing selected text, use Raycast's built-in **Aliases** and **Hotkeys** on any agent or on Dust itself. For example, you can assign `⌥Q` to open a chat directly.

When you highlight content on a page and call Dust in Raycast, the selected content is automatically sent as context to the agent. This is useful for editing an email draft or asking a question about a specific paragraph.
