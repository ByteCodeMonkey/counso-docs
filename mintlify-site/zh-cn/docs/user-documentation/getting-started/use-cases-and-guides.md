---
title: "团队使用场景与指南"
---
Counso 可辅助知识检索、内容起草、资料整理和团队协作。具体能力取决于已配置的连接器、工具、数据范围和用户权限。以下做法可作为场景起点，再按实际流程调整。

## 按团队浏览

- [销售](/zh-cn/docs/user-documentation/getting-started/use-cases-and-guides/sales)：客户准备、会议总结、问题答复和跟进草稿。
- [客户支持](/zh-cn/docs/user-documentation/getting-started/use-cases-and-guides/customer-support)：问题排查、反馈归纳和回复草稿。
- [市场与内容](/zh-cn/docs/user-documentation/getting-started/use-cases-and-guides/marketing)：内容起草、编辑、改写和翻译。
- [工程](/zh-cn/docs/user-documentation/getting-started/use-cases-and-guides/engineering)：代码相关问答、故障资料汇总和文档检索。
- [数据分析](/zh-cn/docs/user-documentation/getting-started/use-cases-and-guides/data-analytics)：整理分析需求、查询辅助和结果说明。
- [知识管理](/zh-cn/docs/user-documentation/getting-started/use-cases-and-guides/knowledge)：查找政策、汇总资料和回答常见问题。
- [招聘与员工支持](/zh-cn/docs/user-documentation/getting-started/use-cases-and-guides/recruiting-and-people)：依据获准政策起草员工答复和招聘资料。
- [产品与设计](/zh-cn/docs/user-documentation/getting-started/use-cases-and-guides/product-and-design)：检查文案、整理反馈和准备发布材料。
- [团队协作](/zh-cn/docs/user-documentation/getting-started/use-cases-and-guides/collaboration)：共享对话、安排跟进和标记待确认事项。

开始前定义资料范围、复核责任和成功标准。更多方法请看[团队试用指南](/zh-cn/docs/user-documentation/getting-started/counso-rollout-guide/designing-use-cases)。
