---
title: "搜索已连接的数据源"
---
Search（搜索）能力会在为智能体选择的数据源中查找相关段落，并将材料用于生成回答。它会根据含义和上下文检索，不只匹配完全相同的关键词。智能体只能搜索已向它开放的数据源和具体位置。

## 选择智能体可以搜索的内容

在 Agent Builder 中，选择工作区提供的相关连接、文件夹、网站、频道或其他位置。范围应与任务相符。来源越聚焦，结果越容易判断，也越不容易混入无关内容。底层来源必须已经连接，并在相应 Space 中可用。

## 按标签筛选

如果来源支持标签，可以用标签缩小搜索范围。must-have 规则要求文档至少包含一个指定标签才会纳入；must-not-have 规则会排除含有任一排除标签的文档。如果界面提供对话中标签筛选，智能体可以使用请求中指定的精确标签值；请确保它与来源中的标签完全一致。

<Warning>
  删除并重新添加 Knowledge 配置可能会丢失已有的 must-have 和 must-not-have 标签筛选条件。请先在复制的智能体上测试，或记录现有筛选条件以便恢复。
</Warning>

## 语义搜索如何工作

比如有人问“育儿假需要准备什么”，即使政策文件没有使用完全相同的措辞，语义搜索也可能找到相关段落。智能体随后结合检索材料和问题起草回答，并在可用时附上来源链接。搜索返回相关材料，但不保证已检查所有匹配文件或表格行。

## 文件系统式导航

智能体还可以像使用文件系统一样浏览受支持的数据源：列出文件夹、查看目录结构，并按路径打开具体文件。目录结构本身有意义或需要读取完整文档时，这项能力可以补充语义搜索，但可能增加工具调用并延长等待时间。

对于 SharePoint Content search，新建 Knowledge 配置默认启用文件夹和路径导航。较早创建的配置可能需要删除后重新添加才能获得该能力。操作前请记录现有标签筛选条件，因为重新添加配置不会保留这些筛选条件。

连接文档中的含义、政策或背景问题适合使用 Search。结构化行数据的精确汇总或计算请使用[表格查询](/zh-Hans/docs/user-documentation/agents/knowledge/table-queries)。
