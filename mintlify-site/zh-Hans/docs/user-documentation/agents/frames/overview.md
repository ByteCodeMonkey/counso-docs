---
title: "MiniApps 概览"
---
MiniApp 可以把智能体输出变成持续更新、可交互的内容，例如报告、仪表盘、计算器、数据可视化或其他交互组件。

<Note>
  MiniApps 在原有静态数据可视化能力的基础上，提供可交互、可修改和可分享的内容。
</Note>

## 使用 MiniApp

MiniApp 可以包含悬停信息、筛选器、按钮、图表等控件。你可以让智能体更改时间范围、增加分类维度、调整布局或尝试其他可视化方式。智能体会更新现有 MiniApp，并保留之前的版本。

对话中创建的所有 MiniApps 都可以通过文件夹图标找到，并可从那里打开、下载或分享。

## 为智能体添加 MiniApps

创建或编辑智能体时：

1. 在 Agent Builder 中打开 **Add capabilities**。
2. 选择 **Create MiniApps** Skill。
3. 保存智能体。

之后即可要求智能体创建报告、仪表盘、可视化或其他交互式输出。

## 撤销更改

如果存在之前的版本，MiniApp 面板会显示 **Revert the last change**。每次操作会撤销一步。你也可以直接要求智能体恢复某个较早版本，例如：**将 MiniApp 恢复到昨天的状态。**

## 管理分享

MiniApp 是可以通过链接分享的文件。根据工作区政策，接收者可以在内部查看和交互，也可能通过安全的外部链接访问。

工作区管理员可在 **Admin > Workspace settings** 中配置分享政策。对外分享前，请确认 MiniApp 只包含计划公开的信息。分享设置负责控制访问权限；修改品牌或展示方式不会自动让私密数据适合公开。
