---
title: "Team use cases and guides"
---
Counso can assist with knowledge retrieval, drafting, organising information, and team collaboration. The available steps depend on configured connections, tools, data scope, and user permissions. Use these examples as starting points and adapt them to the actual workflow.

## Browse by team

- [Sales](/docs/user-documentation/getting-started/use-cases-and-guides/sales): account preparation, meeting notes, answers, and follow-up drafts.
- [Customer support](/docs/user-documentation/getting-started/use-cases-and-guides/customer-support): troubleshooting, feedback summaries, and response drafts.
- [Marketing and content](/docs/user-documentation/getting-started/use-cases-and-guides/marketing): drafting, editing, rewriting, and translation.
- [Engineering](/docs/user-documentation/getting-started/use-cases-and-guides/engineering): code questions, incident summaries, and documentation search.
- [Data analytics](/docs/user-documentation/getting-started/use-cases-and-guides/data-analytics): query preparation, analysis support, and result explanations.
- [Knowledge](/docs/user-documentation/getting-started/use-cases-and-guides/knowledge): policy search, source summaries, and FAQs.
- [Recruiting and people operations](/docs/user-documentation/getting-started/use-cases-and-guides/recruiting-and-people): policy answers and hiring materials based on approved sources.
- [Product and design](/docs/user-documentation/getting-started/use-cases-and-guides/product-and-design): copy review, feedback organisation, and launch drafts.
- [Collaboration](/docs/user-documentation/getting-started/use-cases-and-guides/collaboration): shared discussions, follow-ups, and escalations.

Before starting, define the source scope, review owner, and success criteria. See [Design a useful use case](/docs/user-documentation/getting-started/counso-rollout-guide/designing-use-cases) for a simple way to plan a pilot.
