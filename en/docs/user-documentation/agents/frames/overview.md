# MiniApps overview

Turn Agent outputs into living, interactive content. A MiniApp can be a report, dashboard, calculator, data visualization, or another interactive component generated from a conversation.

<Note>
  MiniApps replace the earlier static data-visualization experience with interactive content that can be revised and shared.
</Note>

## Work with a MiniApp

MiniApps can include hover states, filters, buttons, charts, and other controls. Ask the Agent to change the time range, add a breakdown, adjust the layout, or try another visualization. The Agent updates the existing MiniApp while preserving its earlier versions.

All MiniApps created in a conversation are available from the folder icon. From there, you can open, download, or share them.

## Add MiniApps to an Agent

When creating or editing an Agent:

1. Open **Add capabilities** in Agent Builder.
2. Select the **Create MiniApps** skill.
3. Save the Agent.

You can then ask the Agent to create a report, dashboard, visualization, or other interactive output.

## Revert a change

When a previous version exists, use **Revert the last change** in the MiniApp panel to undo the most recent edit. Reverts apply one step at a time. You can also ask the Agent to restore an earlier version, for example: **Restore the MiniApp as it was yesterday.**

## Manage sharing

MiniApps are files and can be shared through links. Depending on workspace policy, recipients may be able to view and interact with them internally or through secure external links.

Workspace administrators configure the sharing policy under **Admin > Workspace settings**. Before sharing externally, verify that the MiniApp contains only the intended information. Sharing settings control access; changing the branding or presentation does not make private data safe to publish.
